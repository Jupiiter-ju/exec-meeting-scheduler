# แจ้งเตือนนัดหมายล่วงหน้า 1 ชม. ทาง Discord — เวอร์ชัน Google Apps Script

ระบบนี้ **แทนที่** n8n workflow "แจ้งเตือนนัดหมายล่วงหน้า 1 ชม. (Meeting Reminder)" ทั้งหมด
ทำงานเหมือนเดิมทุกอย่าง แต่รันบน Google Apps Script (ฟรี, ไม่ต้องพึ่ง n8n)

- ทุก 10 นาที สคริปต์จะดูปฏิทิน 3 ใบ (คุณกฤช / คุณเบียร์ / Agenix) ว่ามีนัดไหนจะเริ่มในอีก ~1 ชั่วโมง
- อ่านชื่อผู้ขอนัดจาก event → หา Discord ID → ส่ง DM จากบอทน้องจู ข้อความเดิมเป๊ะ
- นัดที่จอง "ทั้ง 2 ผู้บริหาร" (มี 2 event) จะเตือนแค่ครั้งเดียว
- จำไว้ว่านัดไหนเตือนไปแล้ว → ไม่มีทางเตือนซ้ำ แม้ trigger จะรันเหลื่อมเวลา
- ไม่ทำงานวันเสาร์-อาทิตย์

ไฟล์ในโฟลเดอร์นี้

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `reminder.gs` | โค้ดทั้งหมด — วางลงใน Apps Script |
| `appsscript.json` | ไฟล์ตั้งค่าโปรเจค (ใช้เฉพาะถ้าเลือกวิธี B ในขั้นตอนที่ 3) |
| `make_name_map.js` | สคริปต์เล็กๆ สร้างค่า "ชื่อเล่น → Discord ID" จาก export n8n ให้ (รันบนเครื่องตัวเอง) |
| `name_map.local.json` | ไฟล์ที่ `make_name_map.js` สร้าง — **ไม่เข้า git** (มี Discord ID) |

> ⚠️ ห้ามใส่ token หรือ Discord ID ลงในโค้ด/ใน git เด็ดขาด — ค่าพวกนี้เก็บใน **Script Properties** ของ Apps Script เท่านั้น (ขั้นตอนที่ 4)

## ขั้นตอนที่ 1 — เลือกบัญชี Google ให้ถูก

ต้องใช้บัญชี Google ที่ **มองเห็นปฏิทินทั้ง 3 ใบ** (Exe Meeting Schedule, Combo Meeting Schedule, Agenix (AGX) Meeting Schedule)
ปกติคือบัญชีเดียวกับที่ใช้ต่อ credential "Google Calendar Pat001" ใน n8n

วิธีเช็ค: เปิด https://calendar.google.com ด้วยบัญชีนั้น → ดูแถบซ้าย "ปฏิทินอื่นๆ" ต้องมีทั้ง 3 ใบ
ถ้าไม่มีใบไหน ให้เจ้าของปฏิทินกดแชร์ปฏิทินใบนั้นให้บัญชีนี้ (สิทธิ์ "ดูรายละเอียดกิจกรรมทั้งหมด" ก็พอ) ก่อนทำต่อ

**ทำทุกขั้นตอนต่อจากนี้ในเบราว์เซอร์ที่ล็อกอินบัญชีนี้บัญชีเดียว** (ถ้าล็อกอินหลายบัญชี แนะนำเปิดหน้าต่างไม่ระบุตัวตน/Incognito แล้วล็อกอินเฉพาะบัญชีนี้)

## ขั้นตอนที่ 2 — สร้างโปรเจค Apps Script แล้ววางโค้ด

1. เปิด https://script.google.com → กดปุ่ม **"โปรเจ็กต์ใหม่" (New project)** มุมซ้ายบน
2. กดที่ชื่อ "โปรเจ็กต์ที่ไม่มีชื่อ" ด้านบน → ตั้งชื่อ `Exec Meeting Reminder` → ตกลง
3. ในหน้าโค้ดจะมีไฟล์ `Code.gs` เปิดอยู่ พร้อมโค้ดตัวอย่าง `function myFunction() {...}` → **ลบโค้ดตัวอย่างออกให้หมด** (คลิกในโค้ด → Ctrl+A → Delete)
4. เปิดไฟล์ [`reminder.gs`](reminder.gs) ในโฟลเดอร์นี้ด้วย **VS Code** (อย่าใช้ Notepad — ภาษาไทยในไฟล์จะเพี้ยน) → Ctrl+A → Ctrl+C
5. กลับไปที่ Apps Script → คลิกในพื้นที่โค้ดที่ว่างอยู่ → Ctrl+V
6. กด **Ctrl+S** (หรือไอคอนแผ่นดิสก์) บันทึก — ถ้ามีกรอบแดงแจ้ง syntax error แปลว่าวางไม่ครบ ให้ลบแล้ววางใหม่

> ชื่อไฟล์ใน Apps Script จะยังเป็น `Code.gs` ก็ไม่เป็นไร ไม่ต้องเปลี่ยน

## ขั้นตอนที่ 3 — เปิด Google Calendar API ให้สคริปต์ใช้

**วิธี A (แนะนำ, คลิกไม่กี่ที)**

1. แถบซ้ายของ Apps Script หัวข้อ **"บริการ" (Services)** → กดเครื่องหมาย **+** ข้างๆ
2. เลื่อนหา **Google Calendar API** → คลิกเลือก
3. ด้านขวา: เวอร์ชัน `v3`, ตัวระบุ (Identifier) ต้องเป็น `Calendar` (ค่าเริ่มต้น) → กด **เพิ่ม (Add)**
4. ตอนนี้แถบซ้ายใต้ "บริการ" จะมี `Calendar` โผล่มา

**วิธี B (ถ้าวิธี A หาไม่เจอ)** — ไอคอนฟันเฟือง "การตั้งค่าโปรเจ็กต์" → ติ๊ก **"แสดงไฟล์ Manifest 'appsscript.json' ในเครื่องมือแก้ไข"** → กลับไปหน้าโค้ด จะมีไฟล์ `appsscript.json` → ลบเนื้อหาเดิม วางเนื้อหาจาก [`appsscript.json`](appsscript.json) ของโฟลเดอร์นี้แทน → Ctrl+S

## ขั้นตอนที่ 4 — ใส่ค่าลับใน Script Properties

เปิด: ไอคอนฟันเฟือง **"การตั้งค่าโปรเจ็กต์" (Project Settings)** ที่แถบซ้าย → เลื่อนลงล่างสุดถึงหัวข้อ **"คุณสมบัติของสคริปต์" (Script Properties)** → กด **"เพิ่มคุณสมบัติสคริปต์" (Add script property)**
ใส่ทีละคู่ (ช่องซ้าย = Property, ช่องขวา = Value) แล้วกด **"บันทึกคุณสมบัติสคริปต์" (Save script properties)**

### 4.1 `DISCORD_BOT_TOKEN` — token ของบอทน้องจู

token นี้คือตัวเดียวกับที่อยู่ใน n8n credential **"Discord Bot AgentJu"** แต่ n8n ไม่ยอมให้ดูค่าย้อนหลัง จึงมี 2 ทาง:

- **ถ้ามี token จดไว้ที่ไหน** (ตอนตั้ง n8n ครั้งแรก) → ใช้ตัวนั้นได้เลย
- **ถ้าไม่มี** → ต้องสร้างใหม่ที่ https://discord.com/developers/applications → เลือกแอปของน้องจู → เมนูซ้าย **Bot** → กด **Reset Token** → ยืนยัน → กด **Copy**
  > ⚠️ การ Reset Token ทำให้ token เดิม **ใช้ไม่ได้ทันที** — บอทน้องจูใน n8n จะหยุดตอบ จนกว่าจะเอา token ใหม่ไปใส่ใน n8n ด้วย:
  > n8n → Credentials → "Discord Bot AgentJu" → แก้ช่อง Bot Token เป็นตัวใหม่ → Save → เปิดหน้า workflow หลักแล้วกด Save อีกครั้งเพื่อให้ trigger ต่อใหม่
  > ทำช่วงที่ไม่มีคนใช้บอท (เช่นหลังเลิกงาน) และทดสอบทัก DM น้องจูสักคำให้แน่ใจว่าตอบ

วาง token ลงในช่อง Value ของ `DISCORD_BOT_TOKEN` (token ยาวประมาณ 70 ตัวอักษร มีจุด 2 จุด) — **อย่า** ส่ง token ให้ใครหรือวางลงแชท

### 4.2 `NAME_TO_DISCORD` — ตารางชื่อเล่น → Discord ID

รายชื่อนี้ต้องตรงกับ `Resolve Employee` ใน n8n (ชื่อที่ขึ้นในช่อง "ผู้ขอนัด:" ของ event) มีสคริปต์สร้างให้ ไม่ต้องพิมพ์เอง:

1. ต้องมีไฟล์ export ล่าสุดของ workflow หลักอยู่ที่โฟลเดอร์โปรเจคชื่อ `Exec Meeting Scheduler V.1.json` (มีอยู่แล้วปกติ)
2. เปิด Terminal ที่โฟลเดอร์โปรเจค แล้วรัน:

   ```bash
   node apps-script/make_name_map.js
   ```

3. หน้าจอจะบอกจำนวนชื่อ (ตอนนี้ 31 ชื่อ) และบอกว่า **"คัดลอกขึ้นคลิปบอร์ดแล้ว"** — สคริปต์เช็คให้ด้วยว่า ID ของ "เต้" เป็นตัวที่ยืนยันแล้ว (ตัวใน n8n reminder เดิมผิด)
4. กลับไป Apps Script → เพิ่ม property ชื่อ `NAME_TO_DISCORD` → คลิกช่อง Value → **Ctrl+V** → บันทึก
   (ค่าที่วางจะหน้าตาแบบ `{"พี่อัฐ":"1637...","ยีน":"1853...", ...}` บรรทัดเดียวยาวๆ ถูกต้องแล้ว)

เพิ่มพนักงานใหม่ภายหลัง: แก้ `Resolve Employee` ใน n8n ตามปกติ → export ใหม่ทับไฟล์เดิม → รันคำสั่งข้อ 2 อีกครั้ง → วางทับค่าเดิมใน `NAME_TO_DISCORD`

### 4.3 `TEST_DISCORD_ID` — Discord ID ของตัวเอง (ใช้ทดสอบ)

ใน Discord: การตั้งค่า → ขั้นสูง → เปิด **โหมดนักพัฒนา (Developer Mode)** → คลิกขวาที่ชื่อตัวเอง → **Copy User ID** → วางเป็น Value ของ `TEST_DISCORD_ID`

### 4.4 `EXCLUDE_NAMES` (ไม่บังคับ)

ชื่อที่ "ไม่ต้องการ" ให้เตือน คั่นด้วยจุลภาค เช่น `พี่กฤช,พี่เบียร์` — ถ้าไม่มีก็ไม่ต้องสร้าง

## ขั้นตอนที่ 5 — อนุญาตสิทธิ์ (ทำครั้งเดียว)

1. กลับไปหน้าโค้ด → แถบบนมีช่องเลือกฟังก์ชัน (ข้างปุ่ม "เรียกใช้/Run" และ "แก้ไขข้อบกพร่อง") → เลือก **`showConfig`**
2. กด **▶ เรียกใช้ (Run)**
3. จะมีกล่อง **"ต้องมีการให้สิทธิ์" (Authorization required)** → กด **ตรวจสอบสิทธิ์ (Review permissions)**
4. เลือกบัญชี Google (บัญชีจากขั้นตอนที่ 1)
5. ถ้าเจอหน้า **"Google ยังไม่ได้ยืนยันแอปนี้" (Google hasn't verified this app)** → กด **ขั้นสูง (Advanced)** ตัวเล็กๆ ด้านล่างซ้าย → กด **"ไปที่ Exec Meeting Reminder (ไม่ปลอดภัย)"** — ปกติครับ เพราะเป็นสคริปต์ที่เราเขียนเอง
6. กด **อนุญาต (Allow)** ให้ทั้ง 3 สิทธิ์ (ดูปฏิทิน / เชื่อมต่อบริการภายนอก / จัดการ trigger)
7. ด้านล่างจะมี **"บันทึกการดำเนินการ" (Execution log)** โผล่มา ต้องเห็นประมาณนี้:
   ```
   DISCORD_BOT_TOKEN: ตั้งค่าแล้ว
   NAME_TO_DISCORD: 31 ชื่อ → พี่อัฐ, ยีน, ...
   Calendar advanced service: เปิดอยู่
   trigger ที่ติดตั้ง: (ยังไม่มี)
   ```
   ถ้าบรรทัดไหนมี ❌ ให้กลับไปแก้ขั้นตอนที่ 3–4 ก่อน

## ขั้นตอนที่ 6 — ทดสอบส่ง DM

1. เลือกฟังก์ชัน **`testDiscordDm`** → กด ▶ เรียกใช้
2. เช็ค Discord ตัวเอง ต้องได้ DM จากน้องจู: "🔔 ทดสอบระบบแจ้งเตือนนัดหมาย (Apps Script) — วัน..."
3. ถ้า log ขึ้น `Discord /users/@me/channels ตอบ HTTP 401` → token ผิด/วางไม่ครบ (กลับไป 4.1)
   ถ้าขึ้น `HTTP 403 ... Cannot send messages to this user` → คนนั้นปิดรับ DM หรือไม่ได้อยู่ server เดียวกับบอท (ข้อจำกัดเดียวกับตอนใช้ n8n)

## ขั้นตอนที่ 7 — ทดสอบกับนัดจริง (แบบ "เทสระบบ")

เป้าหมาย: ให้สคริปต์เตือน "นัดทดสอบ" มาที่ Discord ของตัวเอง โดยไม่รบกวนใคร

1. เพิ่มชื่อทดสอบลงใน `NAME_TO_DISCORD` ชั่วคราว: เปิด property → แก้ Value โดยเพิ่ม `"เทสระบบ":"<Discord ID ของตัวเอง>",` ต่อท้ายหลัง `{` ตัวแรก → บันทึก
   (เช่น `{"เทสระบบ":"123456789012345678","พี่อัฐ":"1637...` )
2. จองนัดทดสอบผ่าน **หน้าเว็บ** ตามปกติ: ชื่อผู้ขอนัด `เทสระบบ`, บริษัท `TEST`, หัวข้อ `ทดสอบแจ้งเตือน`, **ไม่ต้องใส่อีเมล** (จะได้ไม่มีคำเชิญส่งออกไป)
   เลือกช่องเวลาที่อยู่ **60–70 นาทีข้างหน้า** จากตอนนี้ (ระบบรับนัดเฉพาะ 12:00–15:30 วันทำการ ดังนั้นทดสอบได้ช่วง ~11:00–14:30 ของวันจันทร์–ศุกร์)
3. ใน Apps Script เลือก **`previewNext24h`** → ▶ เรียกใช้ → ใน log ต้องเห็นบรรทัดของนัดทดสอบลงท้ายด้วย `✅ จะเตือน เทสระบบ (...)`
   - ถ้าขึ้น `❌ ไม่พบ "เทสระบบ" ใน NAME_TO_DISCORD` → ข้อ 1 ยังไม่ถูกบันทึก
   - ถ้าไม่เห็นนัดเลย → บัญชีที่รันสคริปต์มองไม่เห็นปฏิทิน (ขั้นตอนที่ 1)
4. ทดสอบรอบจริงแบบไม่ส่ง: เลือก **`dryRun`** → ▶ เรียกใช้ → ถ้านัดอยู่ในช่วง 50–70 นาทีข้างหน้า log จะโชว์ `[dryRun] จะส่งหา เทสระบบ` พร้อมข้อความเต็ม
5. ทดสอบส่งจริง: เลือก **`sendReminders`** → ▶ เรียกใช้ → ต้องได้ DM "⏰ แจ้งเตือนล่วงหน้า ~1 ชั่วโมง ... คุณ เทสระบบ มีนัดหมาย..." → กด ▶ อีกครั้ง log ต้องขึ้น `เตือนไปแล้ว ข้าม` (ไม่ส่งซ้ำ)
6. **เก็บกวาด**: ยกเลิกนัดทดสอบ (ผ่านเว็บหรือบอท) และลบ `"เทสระบบ":"...",` ออกจาก `NAME_TO_DISCORD`
   ถ้าอยากทดสอบซ้ำกับนัดเดิม ให้รัน **`resetDedupe`** ก่อน

## ขั้นตอนที่ 8 — ติดตั้ง trigger ให้รันเองทุก 10 นาที

1. เลือกฟังก์ชัน **`installTrigger`** → ▶ เรียกใช้ → log: `ติดตั้ง trigger แล้ว: sendReminders ทุก 10 นาที`
2. เช็คที่แถบซ้าย ไอคอนนาฬิกา **"ทริกเกอร์" (Triggers)** → ต้องมี 1 แถว: `sendReminders` / ตามเวลา / ทุก 10 นาที
3. (แนะนำ) ในหน้า Triggers เอาเมาส์ชี้แถวนั้น → ไอคอนดินสอ → เลื่อนลง **"การตั้งค่าการแจ้งเตือนเมื่อล้มเหลว"** → เลือก **"แจ้งเตือนฉันทันที"** → บันทึก → ถ้าสคริปต์พังจะมีอีเมลแจ้ง

เสร็จแล้ว 🎉 ตั้งแต่นี้ไม่ต้องทำอะไรอีก

## ขั้นตอนที่ 9 — ปลด n8n ออกจากหน้าที่นี้

ใน n8n workflow **"แจ้งเตือนนัดหมายล่วงหน้า 1 ชม. (Meeting Reminder)"** ต้องเป็น **Inactive** (ตอนนี้ปิดอยู่แล้ว) — **ห้ามเปิดกลับ** ไม่งั้นจะได้ DM ซ้ำ 2 ครั้ง
จะกด Archive/Delete workflow นั้นทิ้งก็ได้ โค้ดต้นฉบับยังอยู่ในไฟล์ `Meeting Reminder 1h.json` ในโฟลเดอร์โปรเจค

## ดูว่ามันทำงานอยู่ไหม / แก้ปัญหา

- แถบซ้าย ไอคอนรายการ **"การดำเนินการ" (Executions)** → เห็นทุกรอบที่ trigger รัน (ทุก 10 นาที) สถานะ "เสร็จสมบูรณ์" คลิกแถวเพื่อดู log ของรอบนั้น
- รอบปกติที่ไม่มีนัด log จะเขียน `พบนัดที่เข้าเงื่อนไข 0 รายการ` — ปกติ
- `ไม่พบชื่อ "xxx" ใน NAME_TO_DISCORD ข้าม` → มีคนจองด้วยชื่อที่ไม่อยู่ในตาราง (เช่นจองผ่านเว็บด้วยชื่อสะกดต่างจาก Discord) → เพิ่มชื่อนั้นลง property ได้ถ้าต้องการ
- `อ่านปฏิทิน xxx ไม่ได้` → บัญชีเสียสิทธิ์ดูปฏิทินใบนั้น หรือยังไม่ได้เปิด Calendar API (ขั้นตอน 3)
- ถ้าเปลี่ยน token ของบอท (Reset Token) ต้องมาอัปเดต `DISCORD_BOT_TOKEN` ที่นี่ **และ** ใน n8n credential ทั้งสองที่
- สคริปต์เก็บความจำ "เตือนแล้ว" ไว้ 36 ชั่วโมงแล้วล้างเอง ไม่ต้องดูแล
- ช่วงเวลาที่ค้นหาคือ 50–70 นาทีข้างหน้า (กว้างกว่ารอบ 10 นาที 1 เท่า) + ย้อนเก็บตกได้ 30 นาทีถ้า trigger รอบก่อนหายไป — ดังนั้น DM อาจมาถึง 50–70 นาทีก่อนนัด ไม่ใช่ 60 นาทีเป๊ะ (ของเดิมบน n8n ก็ ±10 นาทีเช่นกัน)
